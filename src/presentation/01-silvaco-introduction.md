# Silvaco面向半导体设计与智能化应用

Silvaco 提供半导体和光学设计软件解决方案，覆盖：

- **TCAD**：工艺、器件和多物理场仿真。
- **EDA**：电路设计、验证和模型相关工具。
- **IP**：面向 SoC 等系统的半导体 IP 模块与设计工具。
- 应用领域包括显示、传感器、功率器件、存储、智能计算、光伏和 5G/6G 通信。

<!-- 讲师备注：把软件放回产业链中理解，避免把 TCAD 看成孤立的绘图工具。 -->

---

# TCAD是半导体工艺开发的重要工具

TCAD（Technology Computer-Aided Design）通过计算机模型描述：

- 工艺步骤如何改变器件结构；
- 材料、掺杂和缺陷如何改变载流子输运；
- 结构和偏压如何共同决定电流、电场与击穿行为。

它连接了**工艺开发、器件设计、实验验证和电路模型提取**。

<!-- 讲师备注：强调 TCAD 的核心不是“画结构”，而是将工艺和物理规律转化为可计算的问题。 -->

---

# TCAD补充实验无法直接观测的信息

实验可以测得端口电流、电压和其他外部响应，但通常难以直接确定器件内部的原因。

TCAD 可以帮助回答：

- 高反偏电压下，哪个区域首先出现高电场？
- 某一电压下发生击穿的物理原因是什么？
- 反向电流—电压曲线的拐点对应怎样的内部状态？
- 半导体内部哪些区域发生了电离、复合或载流子拥挤？

<!-- 讲师备注：用“外部测量结果”和“内部物理解释”作对照。 -->

---

# TCAD参与设计技术协同优化（DTCO）

TCAD 是 DTCO（Design-Technology Co-Optimization）的一部分，可与以下环节协同：

- 工艺流程和版图设计；
- SPICE 模型建立与校准；
- RC 参数提取；
- 电路性能、功耗和可靠性优化。

TCAD 与 SPICE 的协同，使器件层面的结构和工艺变化能够传递到电路设计决策中。

<!-- 讲师备注：说明器件仿真结果的价值在于能够进入后续模型和电路流程。 -->

---

# 仿真需要与实验相互校准

半导体器件和工艺通常包含多个耦合因素。可靠的建模流程应当：

1. 根据实验结果或文献确定材料和工艺参数。
2. 建立结构、物理模型和边界条件。
3. 将仿真输出与实验测量进行对比。
4. 解释差异来源，再决定是否修正模型。

**仿真不是实验的替代品，而是解释、预测和优化实验的工具。**

<!-- 讲师备注：这是后续学生 PPT 和报告中必须遵守的证据链。 -->

---

# Silvaco工艺仿真：从结构到工艺历史

工艺仿真通常按时间顺序描述器件形成过程：

**初始结构 → 网格 → 材料与掺杂 → 刻蚀/沉积 → 扩散/注入 → 结构输出**

每个工艺步骤都会改变后续仿真的初始条件，因此应保存关键步骤的结构文件和参数。

<!-- 讲师备注：让学生理解工艺仿真是有历史的，不是只对最终结构做一次计算。 -->

---

# 实体建模建立初始结构

实体建模从尺寸和材料出发建立器件结构，包括：

- 区域和材料的几何边界；
- 电极位置与接触关系；
- 初始掺杂或载流子分布；
- 二维或三维器件的空间范围。

例如，FinFET 结构可以先用几何尺寸定义鳍、栅介质、栅电极和衬底，再进入工艺步骤仿真。

<!-- 讲师备注：强调结构文件是器件仿真的输入合同之一。 -->

---

# 刻蚀与沉积改变器件几何

工艺仿真需要描述：

- 刻蚀速率和方向；
- 沉积层的厚度和覆盖范围；
- 工艺步骤后的边界移动；
- 结构转角、凹槽和薄膜界面的变化。

几何变化会进一步改变局部电场、载流子路径和寄生参数。

<!-- 讲师备注：由几何变化引出“工艺参数最终会影响电学性能”。 -->

---

# 形貌变化需要物理模型

形貌模型可以根据晶体学、材料属性和工艺条件描述：

- 各向异性和各向同性刻蚀；
- 薄膜沉积与界面形成；
- 复杂结构中的边界演化；
- 材料属性对表面形貌的影响。

模型精度、计算成本和可获得的工艺参数需要共同权衡。

<!-- 讲师备注：提醒学生不要只看几何结果，还要说明几何是由什么模型产生的。 -->

---

# 注入、扩散和退火决定掺杂分布

离子注入和热处理模型通常需要关注：

- 注入离子种类、剂量和能量；
- 注入角度以及沟道效应；
- 扩散系数和温度历程；
- 退火造成的激活与分布变化。

最终掺杂分布会影响结深、阈值电压、导通电阻和击穿电压。

<!-- 讲师备注：把工艺参数与后续可测电学指标建立对应关系。 -->

---

# 光学模型按速度与精度分层

Silvaco 光学仿真可以按计算代价和物理完整性选择模型：

| 方法 | 主要特点 |
| --- | --- |
| 光线追踪 | 速度快，适合几何光学近似 |
| 传递矩阵 | 适合层状结构和薄膜光学分析 |
| 光束传播 | 适合传播方向明确的波束问题 |
| 有限差分时间域 | 能处理完整三维电磁传播，但计算量较大 |

模型选择应与器件尺寸、波长、结构和问题目标匹配。

<!-- 讲师备注：强调“更复杂”不等于“总是更合适”。 -->

---

# 光电器件是多物理场耦合问题

典型应用包括：

- 太阳能电池：光吸收、载流子产生与收集；
- 图像传感器：光生载流子与像素结构；
- LED：载流子注入、复合、发光和光提取；
- 光学交流分析：光场和器件响应的频域关系。

分析时需要同时说明光源、材料、结构、偏压和观测物理量。

<!-- 讲师备注：为后续光电器件选题提供问题模板。 -->

---

# PiN功率器件的DC分析

PiN 结构的直流分析可以关注：

- 纵向掺杂浓度分布；
- 电流—电压关系；
- 高压下的电场分布；
- 温度变化下的器件响应。

仿真图不能脱离条件解释：必须同时给出器件结构、端口偏压、温度和模型设置。

<!-- 讲师备注：提醒学生“DC 特性”不是单独一条曲线，而是有明确边界条件的结果。 -->

---

# 网格决定空间分辨率与计算成本

网格策略需要在精度和计算量之间平衡：

- 器件边界处需要足够分辨率；
- 结底部和高场区域通常需要局部加密；
- 材料界面附近应避免过粗网格；
- 三维模型的网格数量会显著增加内存和求解时间。

网格加密应服务于物理问题，而不是平均地增加所有网格点。

<!-- 讲师备注：要求学生在报告中说明网格独立性或至少说明局部加密理由。 -->

---

# SiC工艺仿真：离子注入是关键步骤

宽禁带半导体 SiC 的工艺分析可以包括：

- 不同注入条件下的掺杂浓度分布；
- 三维结构中的刻蚀和材料界面；
- 注入能量对掺杂深度的影响；
- 后续激活和退火对器件参数的影响。

<!-- 讲师备注：把 SiC 案例作为工艺参数、结构和电学结果的连接点。 -->

---

# 铝离子注入能量影响分布深度

示例中比较四种铝离子注入能量：

| 条件 | 注入能量 |
| ---: | ---: |
| 1 | 360 keV |
| 2 | 200 keV |
| 3 | 90 keV |
| 4 | 40 keV |

一般而言，注入能量越高，离子进入材料的平均深度越大；实际分布还受到材料、剂量、注入角度和退火条件影响。

<!-- 讲师备注：不要只依据峰值深度下结论，应同时看剂量和分布宽度。 -->

---

# SiC JBS保护环影响击穿特性

SiC JBS 结构的击穿仿真可以比较不同保护环数量下的反向电流—电压关系：

- 保护环用于调节边缘电场；
- 环数量和间距会改变电场分布；
- 反向电流快速增加的区域对应接近击穿的工作状态；
- 需要同时记录结构尺寸、掺杂、偏压扫描范围和收敛设置。

<!-- 讲师备注：让学生区分“曲线变化”与“造成曲线变化的电场机制”。 -->

---

# SiC JBS电场：0 V至1400 V

观察电场随反向偏压的变化：

- **0 V**：建立零偏压下的基线分布。
- **400 V**：耗尽区扩展，电场开始明显重排。
- **1200 V**：高场区域更加集中，需要关注边缘终端。
- **1400 V**：接近击穿状态，局部峰值电场成为主要风险。

同一器件的不同偏压结果应使用一致的色标和坐标，便于比较。

<!-- 讲师备注：将多张云图转成可复述的比较逻辑。 -->

---

# SiC JBS电流密度与电势

除电场外，还应查看：

- **电流密度**：判断导电路径和局部电流拥挤；
- **电势**：观察偏压如何在结构内部展开；
- **材料界面**：解释电势和电场变化的位置；
- **保护环区域**：判断边缘终端是否有效。

结果解释应形成链条：

**偏压 → 电势分布 → 电场分布 → 电流密度 → 击穿响应**

<!-- 讲师备注：这是阅读 TCAD 结果图的通用顺序。 -->

# 本章小结

- TCAD 连接工艺、器件、实验和电路模型。
- 工艺仿真通过结构、网格、材料和工艺历史生成器件输入。
- 光学、热学和电学模型需要根据问题目标选择复杂度。
- SiC JBS 案例说明：结构设计最终要通过电场、电势、电流密度和击穿曲线验证。

**下一步：从一个明确的器件问题出发，建立可复现的仿真输入和输出。**
