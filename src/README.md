# 微电子器件建模与仿真

## 课程定位

本课程面向广东工业大学相关专业研究生，围绕微电子器件的物理模型、数值方法、仿真流程与结果分析展开。课程资料将逐步补充讲义、示例和课堂演示文稿。

## 学时与考核

- **总学时：32 学时**。
- **平时分：40%**，结合课堂参与、阶段任务和学习过程评价。
- **考试分：60%**，不安排笔试；每位学生围绕指定或自选主题完成一次 PPT 讲解，并提交配套报告。

PPT 和报告应说明问题背景、模型假设、仿真设置、结果分析和局限性。具体选题范围、提交格式、汇报时长和评分量表以课堂通知为准。
